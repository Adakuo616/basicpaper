# 流量網路可靠度學習網

九篇多狀態（隨機）流量網路可靠度基礎論文的互動學習儀表板，對象是碩博士生。

## 內容

| 站點 | 論文 |
|---|---|
| s | 基礎營地：共同語言（d-MP、d-MC、聯集機率） |
| P2 | Jane, Lin, Yuan (1993) IEEE TR：以最小割集求 d-MC |
| P1 | Lin, Jane, Yuan (1995) Networks：以最小路徑求 d-MP |
| P3 | Lin (2001) C&OR：節點故障 |
| P4 | Lin (2001) CAMWA：多商品可靠度 |
| P5 | Lin (2007) C&OR：雙商品、不可靠節點、預算（MC） |
| P6 | Lin (2002) JORSJ：專案網路的較長／較短邊界工期向量 |
| P7 | Lin (2003) C&OR：最快路徑問題的可靠度 |
| P8 | Lin (2010) IEEE TR：兩條 MP 的備援路由與預算 |
| P9 | Lin & Yeh (2011) ASOC：以 GA 求傳輸線最佳指派 |
| t | 研究前沿：統整模板、共同假設、研究方向 |

## 功能

- **學習網路圖**：把學習路線畫成 s→t 的流量網路。掌握一站，它的出弧就會通電，開放下一站。
- **每站深度內容**：動機、模型、定義、定理與證明思路、演算法、數值範例、複雜度、邊界情況、貢獻與延伸。
- **自我檢測**：選項每次重新洗牌，答錯不直接公布答案；另有開放題，要求用自己的話說明。
- **AI 助教**（需在 claude.ai 開啟）：自由問答、考考我（蘇格拉底式）、批改我的說明，以及 ELI5／ELI14／實習生／研究生深挖四種解釋層次。
- **演算法實驗室**：逐步重現 P1、P2、P7 的數值（d-MP、d-MC、最快路徑下邊界點與可靠度）。
- **練習題**：實驗室 Excel 練習的互動版（RSDP 手算、論文 3 節點故障、論文 6 窮舉、多路徑最快路徑加預算）。
- **程式教學**：51 支 MATLAB 程式的導讀，標出每支對應的論文步驟、資料格式約定與注意事項，並可請 AI 逐行解釋、對應論文、找問題或改寫成 Python。
- **理解檢查清單**：另見 `LEARNING_CHECKLIST.md`。

> 原文 PDF、MATLAB 原始碼（`practice-data.js`）與研究工具 PDF 只隨內部儀表板發布，不放進這個 repo。

## 檔案

- `index.html`：頁面與樣式
- `papers.js`：九篇論文的知識庫（同時供 AI 助教當作脈絡）
- `app.js`：互動邏輯、計算引擎、AI 串接
- `practice.js`：練習題與程式教學的頁面邏輯和程式導讀

直接用瀏覽器開啟 `index.html` 即可使用（AI 助教除外）。
